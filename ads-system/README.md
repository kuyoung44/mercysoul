# MercySoul Ads Command Center

A Notion + Meta Ads + Make.com operating system for MercySoul.

## Locked operating assumptions

- Goal: Lead generation -> WhatsApp -> sale
- Monthly test budget: NGN 50,000
- Primary offer: MercySoul Vision Brain custom AI artwork, starting at NGN 5,000
- Audience: Nigerian SMEs, founders, entrepreneurs, creators and professionals
- Primary conversion: qualified lead
- Sales channel: WhatsApp
- Currency: NGN

## Files

- `notion-schema.md` — database properties, relations, rollups, views, formulas and copy/paste setup
- `make-scenario.md` — Make.com Facebook Lead Ads -> Notion scenario with operation-saving design
- `campaign-plan.md` — campaign, audience, budget and creative plan
- `csv/` — five CSV import templates with three sample rows each

## Notion databases

1. Campaigns
2. Leads
3. Creatives
4. Daily Performance
5. Weekly Review

## Funnel

Meta Ad -> Lead Form -> Facebook Lead -> Make.com -> Duplicate Check -> Notion Lead -> WhatsApp -> Customer -> Revenue -> ROAS

## Core formulas

CTR = Clicks / Impressions * 100
CPC = Spend / Clicks
CPL = Spend / Leads
Conversion Rate = Leads / Clicks * 100
ROAS = Revenue / Spend

## Make free-plan rule

Design the lead flow for approximately 3-4 operations per lead. Do not create a daily-performance record for every lead. Keep raw Meta delivery metrics in Meta Ads Manager and use Notion for CRM, decisions and weekly analysis.
