# MercySoul Obsidian Vault

This directory is designed to be opened as an Obsidian vault.

The vault is GitHub-backed so architecture, security decisions, deployment notes, engine lifecycle documentation, and audit principles remain version-controlled.

## Important
Do not place secrets, API keys, access tokens, private keys, or credentials in this vault.

Use Obsidian for knowledge and documentation. Use the MercySoul Engine for controlled execution.
