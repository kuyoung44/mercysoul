# Decision Log

## 2026-09-28 — Engine beyond AI
**Decision:** MercySoul is being built as an execution-control engine with AI as a component.

**Required lifecycle:** STOP → VERIFY → AUTHORIZE → EXECUTE → VERIFY_RESULT → AUDIT.

**Reason:** A useful AI response is not equivalent to verified system execution.

## 2026-09-28 — GitHub-backed Obsidian vault
**Decision:** Use the MercySoul GitHub repository as the source-controlled Obsidian knowledge layer.

**Boundary:** The vault documents and organizes knowledge; it does not grant execution authority.
