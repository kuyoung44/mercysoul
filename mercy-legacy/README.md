# MercyLegacy

CREATE · PLANT · CONNECT

MercyLegacy is the living legacy layer of MercySoul: digital legacy identities connected to trees, places, QR/NFC markers, memories, and a Forest Map.

## MVP
- Legacy profiles
- Tree registry
- QR identities
- Forest sites
- Timeline and memories
- Privacy permissions
- Legacy Brain integration point

## Stack
Next.js · Vercel · Supabase · PostgreSQL

## Principle
Create the story. Plant the legacy. Connect the living network.
