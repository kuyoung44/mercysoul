# MercySoul Relationship Context

The Relationship Context Engine translates visual and social UI cues into **context only**. It does not establish identity, friendship, location, consent, or independent online presence.

## Supported conceptual signals

- 🌍 Golden Earth / globe → global-vision context
- ✨ Gold light and geometric lines → Vision Brain / Creation Engine aesthetic
- 🧬 Interconnected geometry → systems and human-connection context
- 🔱 Ancient-looking symbols → symbolic/archival aesthetic only; no historical or spiritual claim is inferred
- 📱 Social/profile UI → connection-layer context
- 📍 Map/location UI → location-aware context only with explicit consent
- 🔒 Private-friendship UI → privacy boundary
- 🎨 Chat customization → personalized creative experience
- 🟢 Displayed online indicator → displayed-status context only; never proof of activity elsewhere

## Non-negotiable boundaries

1. Visual similarity is not evidence of identity or relationship.
2. A profile or friendship UI is not proof of a relationship outside the displayed service.
3. An online indicator is not proof of independent activity.
4. Location and external profile data require explicit user consent.
5. The engine must not scrape or infer private data from connected social services.
6. Security and privacy remain higher priority than creative interpretation.
