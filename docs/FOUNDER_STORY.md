# MercySoul Dominion — Founder Story

## Building from Oyan

MercySoul Dominion is being built from Oyan, Osun State, Nigeria—through ideas, engineering, a smartphone, internet access, AI tools, persistence, and a belief that meaningful technology can emerge from anywhere.

The initiative is developing an ecosystem spanning AI, software engineering, creative intelligence, workflow automation, and digital innovation.

Its core engineering principle is:

**No approval = No execution.**

Intelligence should be useful. Creativity should create value. Technology should be governed responsibly. The systems are evolving, and the work should be demonstrated through code, tests, working products, and verifiable progress—not inflated claims.

**From Oyan to the world.**
